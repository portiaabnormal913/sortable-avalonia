## 📋 What is sortable-avalonia?

sortable-avalonia is a desktop app for Windows. It helps you sort, swap, and move items across lists and collections using simple drag and drop. The interface uses Avalonia UI, which means it feels smooth and responds well even when you move many items.

This tool fits well if you manage boards or lists, like kanban style, or any sortable grid. You don’t need technical skills to use it. Just drag items where you want, and the app keeps the order for you.

## ▶️ How to Use sortable-avalonia

- Find the app icon on your desktop or in your Start menu.
- Double-click to open it.

### Main Functions

- **Sorting Items:** Click on any item in the list and drag it up or down to reorder.
- **Swapping Items:** Drag one item over another. They will exchange places.
- **Cross-Collection Transfer:** Move items from one list or board to another by dragging. The app updates instantly.

- Main grid area displays items you can sort or move.
